# Paperkites

A quiet, offline-first Markdown notes app for macOS. <https://paperkites.app>

This repository holds the releases and the bug tracker; the app's source is private.

## Download

[The latest beta](https://github.com/thearyanahmed/paperkites-releases/releases): the `.dmg` for macOS 12+ on
Apple silicon. Intel Macs and Linux aren't supported yet. Paperkites updates itself
from here.

## Report a bug

Run `:bug` in Paperkites, or Help → Report a Bug… on macOS. It opens [the bug form](../../issues/new/choose)
with your version filled in.
